# 本地图书整理工作台

## 运行结构

Python 负责领域逻辑、解析、AI 校订、存储和导出；React/TypeScript 提供本机浏览器管理界面。FastAPI 绑定回环地址，同源会话和 CSRF 校验保护写入。用户正文以文本显示，不执行书中的 HTML 或脚本。

后台协调进程读取 SQLite 任务队列，每次在可终止的子进程执行任务。解析、OCR 和模型调用与 HTTP 服务分离；暂停和取消通过租约及执行令牌阻止失去执行资格的进程继续提交。

## 数据模型

原始文件按字节哈希不可变保存，提取产生带定位信息的结构块。来源区间以 Unicode 码点左闭右开范围表示，和图书/版本建立多对多归属；未使用区间的处置单独记录。

图书表示作品身份，版本表示语言、译者或修订差异。整理稿修订冻结正文、元数据与来源；可变分支头使用比较并交换更新，避免后提交覆盖先提交。每次文字替换或删除记录输入区间、原文哈希、输出块与操作者。输出文字由来源拷贝或明确编辑区间覆盖；父修订必须位于实际祖先链。

结构块保留原结构和资源。当前文字编辑会标记原结构过时，导出用新文字并报告降级，避免把旧表格内容伪装成已修订结果。

## 候选与校订

文本指纹只用于候选检索；原文字节/码点比较才可证明精确相同。规范化、繁简或布局差异不构成可删除原文的依据。检索和差异比较有明确预算，超限显示未穷尽或未决区域。

AI 请求绑定冻结修订，长书按单次预算分片，保留原始码点坐标；材料仅包含当前图书版本已归属的局部来源区间。证据来自祖先映射和同版本有界词片段召回，不使用跨书兜底。模型不掌握应用执行权；响应只生成校订提案，应用验证格式、原文与证据范围后等待用户接受。同一冻结修订与分支产生的非重叠分片提案可以逐个应用；发生其他编辑或重叠时停止自动定位。

原文内的指令不改变应用规则。模型建议不会自动改数字、补写章节或合并不确定版本。HTTP 调用发生未知结果时保持待处理，避免自动重复计费。

来源检查以明确归属区间为检索证据，来源级指纹只缩小查找范围。候选之间不传递图书身份。同一块内不同位置也可产生边界线索，文风变化不作为作品身份判据。候选表中的来源核查请求和人工核查状态独立于旧版相似来源候选；请求、报告和响应都有对象引用，参与完整性检查、备份与缓存保护。核查意见不授权自动归属。

批量归属计划冻结待处置的未归属区间、题名线索和匹配证据。匹配多义时保留候选，创建图书、版本和归属须由人工确认。提交在同一事务中复核来源提取哈希及书库归属、处置的变更序号，再登记决定和归属。纠错对比现有归属范围、目标与提取哈希，记入变更事件。既有整理稿继续指向生成时复制的原文区间。

组稿计划冻结底本及补充来源的提取哈希、归属和图书版本信息，按底本顺序列出精确重复、可比较的异文、可定位的补充和待核区间。精确比较考虑文字、结构和资源。近似文字匹配和有限拆并段只提供候选，采用时复制冻结选项的原文区间。定位不明的补充需在其他流程手工选取。处理预算包括提取字节、归属区间、文字及计算量，截断的组稿计划不得提交。

生成计划受任务执行租约保护。组稿提交在写事务中再次核对快照，和新分支、修订及选择记录一并提交。重复提交相同决定和标题可读取既有结果。显式同意跨版本后，底本仍绑定目标版本，补充范围可以来自同书其他版本。方案冻结涉及的版本与归属，阻止采用同时归属不同图书的重叠范围。生成整理稿时保留各版出处，无须重复写入原有归属。归属和组稿历史有持久的内容对象引用，生成后的计划及其已保存决定可以按历史计划重新读取。

编码重读和文字恢复产生新的提取记录，绑定同一原件与父提取哈希，旧归属和修订不重写。TXT 在章标题处分块，过长正文按最多 4096 码点切为处理块，仍完整覆盖解码文本。分块不代表作品分界。DOC 转换受独立监督进程和现有任务进程边界约束，转换器不可用的提取可显式重试，不作为永久成功缓存。

## 存储、任务与恢复

内容对象先写临时文件并校验，再原子发布。元数据提交后才可见；中断产生的无引用对象由明确的维护规则处理。原件、修订和可重试输入通过引用保护。

任务有幂等输入键、状态、检查点、执行令牌与租约。耗时阶段在写事务外执行，最终提交再检查执行资格。导出与任务身份绑定，已有完整件校验后复用；缺少完成标记的任务输出可安全重建。

来源和图书目录通过服务端筛选和分页查询。来源可按已归属图书和版本筛选，目录访问覆盖历史条目。计划历史和关联数据可以按需查询，无须从启动状态的有限条目推断全库。

备份使用数据库一致性快照和引用闭包，恢复到新目录后重新验证。项目运行与维护均不依赖工作区基础设施。缓存清理、工程任务清理和用户书库内容管理是不同所有者。

## 当前取舍

工作台提供人工确认的归属、组稿与校订流程，并用范围匹配和有界底本比较辅助取舍。证据只覆盖本次参与比较的来源和范围。作品身份、版本边界、缺章与完整性需要结合原件核实，复杂表格、公式和 OCR 结果也需要人工复核。备份和导出不会自动过期删除。

这些限制在界面和使用文档中说明；算法评估、额外格式适配与更细的语义对齐可以在现有原件/修订模型上扩展。
