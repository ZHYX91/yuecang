# 书库与空间管理

一个书库目录包含：

| 路径 | 用途 |
| --- | --- |
| project.json / library.sqlite3 | 项目标识、元数据、分支、任务与提案 |
| objects | 以 SHA-256 寻址的原件、提取结果、资源和修订 |
| tmp | 任务临时文件 |
| exports | 用户明确生成的导出 |
| backups | 用户明确生成的独立快照 |
| provider-key | 本地模型密钥；不会进入备份 |

书库必须在支持 SQLite 锁和原子重命名的本地普通目录，不经过符号链接或 Windows 重解析点。不要把活动数据库放在网络共享或双向同步盘。原件和人工修订会保留，存储增长应根据实际导入量管理。

## 备份与恢复

设置页可创建备份。快照使用 SQLite backup API，并复制该快照实际引用的内容对象和已登记导出；每个文件有哈希清单，不复制旧备份、密钥和无引用临时内容。

恢复总是写入新的空目录，不覆盖已有书库：

```powershell
.\runtime\python.exe -I -m yuecang --project D:\Books\Restored restore D:\Books\MyLibrary\backups\快照编号
.\runtime\python.exe -I -m yuecang --project D:\Books\Restored verify
```

恢复后未完成的任务暂停，模型凭据需重新设置。Windows 下自选书库目录应仅允许自己的账号访问；程序拒绝密钥文件链接，但不自动改写用户目录 ACL。POSIX 系统的密钥文件权限为 0600。备份清单损坏、文件缺失或对象哈希不一致时停止恢复。

## 缓存与容量

默认临时空间预算 2 GiB，最低剩余空间 256 MiB，可在设置中调整。并发写入通过 SQLite 共享预留量控制；任务不足空间时停止新增写入，不删除原件腾空间。提取和导出另有格式安全上限。

缓存清理只处理产品登记、已停用且符合保留期的临时内容。活动任务、有效预留、可重试输入、原件、修订、提案依赖、导出和备份保持受保护；不按目录名称猜测所有权。未登记的历史临时目录需要单独核实。

导出和备份是用户成果，不会自动清理。定期检查大小、保留必要副本后由用户管理。回收报告区分逻辑删除量和卷空闲量变化；WSL 动态磁盘的内部删除不会自动缩小宿主 VHDX。
