# 阅藏 YueCang

阅藏是运行在自己电脑上的图书整理工作台。它把文件、图书、版本和整理稿分开管理：完整书、残章、混合书籍文件和不同版本都可以作为来源，选取有依据的内容汇成可导出的整理稿。

本机浏览器提供管理界面，Python 服务和后台任务在本机运行，书库使用普通文件和 SQLite。只有主动配置并发起 HTTP 模型审阅，才会向指定服务发送当前书籍已归属的审阅材料。

## 开始使用

Windows 便携包解压后运行 `start.cmd`，浏览器打开 `http://127.0.0.1:8765`。包内自带 Python 和管理界面。在启动窗口按 Ctrl+C 可正常停止服务，正在执行的本地任务转为可继续状态；异常退出由下次启动检查租约后恢复。

默认书库在 Windows 的 `%LOCALAPPDATA%\YueCang\Library`。指定其他盘或目录：

```powershell
.\start.cmd --project D:\Books\MyLibrary serve
```

从源码安装、运行和构建见[开发指南](docs/development.md)。

## 整理一本书

1. 导入来源文件，查看提取结果、编码候选、缺失资源和 OCR 提醒。TXT/Markdown 可预览后重新解码或修复常见乱码。
2. 建立图书和版本。一个混合文件可以按内容块或文字区间分别归属多本书。
3. 查看疑似混书提醒，必要时导出局部线索交给 AI 核查。同版本的已归属来源可以对齐，比较重复、独有和冲突范围，再按顺序选入整理稿。
4. 编辑文字，或生成 AI 审阅请求。离线 JSON 和 HTTP 模型均产生待确认提案，接受后才修改整理稿。
5. 对照来源和修改历史，确认后定版，导出 Markdown、TXT 或 EPUB。草稿导出需要明确选择。

每次编辑保留旧修订；可恢复历史修订作为当前分支。AI 不负责证明一本书已完整，也不应凭空补齐缺章。

## 格式与边界

| 输入 | 支持范围 |
| --- | --- |
| TXT / Markdown | 编码选择与候选预览、可逆乱码恢复；章节及文本块、Markdown 表格、代码、图片引用 |
| EPUB | 按 spine 顺序提取，保存本地资源 |
| DOCX | 正文顺序、表格、图片、脚注及无法可靠转换的结构提示 |
| DOC | 通过已安装的 LibreOffice 转为 DOCX 后提取；Windows 可明确选择 Word/WPS，须通过实例归属与宏禁用检查 |
| PDF | 文本页提取；扫描页可选择 OCR |
| PNG / JPEG / TIFF 等图片 | 保留原图，可选择 OCR |

OCR 需要另行安装 Tesseract 和相应语言包，不自动下载。复杂排版、公式、扫描件不能保证无损还原；问题会保留在来源或导出报告中。当前单文件上限 256 MiB，压缩包展开上限 512 MiB。Markdown 引用的外部配图不会自动从其他目录搜集，缺失会提示。

DOC 默认仅自动选用 LibreOffice，转换器不随产品打包。来源提醒、局部匹配和同版对齐均有处理上限；没有发现线索不证明只有一本书，独有范围也不证明另一份整书缺章。编码恢复单次上限 16 MiB，确认后生成独立新来源，原件及已有整理稿保留。

“最优版本”是基于来源比较和人工确认形成的整理稿，不等同于最长版本、多数票或模型自动生成的版本。不同译本、改写本和修订版应分开管理。
